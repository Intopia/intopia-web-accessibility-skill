An accordion is a group of disclosures, where each disclosure's button is wrapped in a heading element. It extends the Disclosure pattern (`references/acceptance-criteria/Acceptance Criteria - Disclosure.md`) — apply Disclosure's criteria to each disclosure/panel pair in the group, then apply the additional criterion below.

### Semantic markup

*   The disclosure button is wrapped in an element with a role of heading in the accessibility tree.
    
    *   **Type:** WCAG
        
    *   **Success Criteria:** 1.3.1 Info and Relationships
